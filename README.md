# Stochastic Dynamical Models: CAVI Algorithm
> **Coordinate Ascent Variational Inference and the Two-Node Ising Model**

## 📌 Project Overview
This repository contains the final report for the **Methods and Models for Statistical Mechanics** course. The project analyzes the convergence limits of the **Coordinate Ascent Variational Inference (CAVI)** algorithm applied to a two-node Ising model, studying its behavior and properties as a discrete dynamical system.

## 🧪 Mathematical Framework
The analysis explores the intersection of statistical mechanics and approximate Bayesian inference techniques:
* **Two-Node Ising Model**: Formulation of the spin interactions and energy landscape.
* **CAVI Algorithm Dynamics**: Implementation and theoretical evaluation of the Coordinate Ascent Variational Inference.
* **Convergence Limits**: Rigorous investigation of the algorithm's convergence properties and fixed points within the framework of discrete dynamical systems.

## 📂 Repository Structure
* `docs/`: Contains the official academic documentation.
    * `Final_Report.pdf`: Comprehensive analysis, mathematical derivations, and conclusions regarding the CAVI algorithm on the Ising model.
* `images/`: (Optional) Diagrams of the dynamical system and convergence plots.
